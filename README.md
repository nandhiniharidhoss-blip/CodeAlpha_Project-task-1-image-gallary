\# Image Gallery



\## Project Description



This project is a responsive Image Gallery website developed using HTML, CSS, and JavaScript.



The gallery displays images in different categories such as Animals, Birds, Nature, Insects, and Flowers. Users can click on an image to view it in a larger lightbox view and use the Previous and Next buttons to navigate between images.



\## Features



\- Responsive image gallery

\- Multiple image categories

\- Lightbox image preview

\- Previous and Next navigation

\- Close button for lightbox

\- Hover effects

\- Smooth transitions

\- Responsive design for different screen sizes

\- Clean and attractive user interface



\## Technologies Used



\- HTML5

\- CSS3

\- JavaScript
